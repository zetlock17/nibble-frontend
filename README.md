# Клёв

Веб-сервис для рыбаков Владивостока и окрестностей: карта мест по видам рыб, лента уловов, погода, справочник и подборки снастей с переходом на Фарпост.

В репозитории пока стартовое приложение React + TypeScript + Vite. Продуктовые функции предстоит реализовать.

## Документация

- [Концепция](docs/CONCEPT.md): что делаем, пользовательские сценарии, предлагаемая первая версия, связи данных и открытые решения.
- [Правила для агента](AGENTS.md): обязательные навыки, подход к коду, дизайну, текстам и проверкам. Читать в начале каждой сессии.

## Запуск

Нужны Node.js и npm, совместимые с установленной версией Vite. Зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

## Проверки и сборка

```sh
npm run lint
npm run build
npm run preview
```

`preview` позволяет посмотреть собранное приложение локально после `build`.
