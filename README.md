# Клёв

Веб-сервис для рыбаков Владивостока и окрестностей: карта мест по видам рыб, лента уловов, погода, справочник и подборки снастей с переходом на Фарпост.

Начата визуальная вёрстка на React + TypeScript + Vite. Готовы хедер, боковая навигация, погодная карточка, лента и профиль на моках. В ленте работают фильтры по источнику, месту и виду рыбы, сброс, локальные лайки и подписки. Поиск, выбор города, публикация улова, комментарии и редактирование профиля ещё не подключены к продуктовой логике.

Профиль открывается из бокового меню и по кнопке пользователя в хедере. Показывает обложку, инициалы, имя, город, описание, количество постов и подписчиков. Ниже используются общие карточки `PostCard`, без подписки на себя. Вкладок «Уловы / Коллекция» и счётчика подписок нет. Данные находятся в `src/mocks/profile`, фотография переиспользуется из демонстрационной ленты. Кнопки публикации и редактирования отключены до подключения соответствующих форм.

Справа от постов на широком экране расположен блок «Фото с рыбалок», занимающий оставшуюся ширину. Сетка содержит восемь снимков и меняется от двух до четырёх колонок по ширине блока. На узком экране он находится над лентой. Общий компонент `PhotoGrid` открывает снимок в новой вкладке и обрабатывает пустой альбом и ошибку изображения. Альбом пока использует отдельные иллюстративные моки `src/mocks/profile/photos.ts`, а не фото из постов. Источники: [src/assets/images/profile/SOURCES.md](src/assets/images/profile/SOURCES.md).

Демонстрационные карточки показывают пользователей сервиса и Telegram, записи с фото и без фото, с необязательными сведениями об улове. Реальный парсинг Telegram пока не подключён. У вымышленной публикации «Источник» отображается без ссылки. Компонент принимает HTTPS-ссылку на `t.me` при подключении оригинальных публикаций. Лайки и подписки сбрасываются после перезагрузки страницы.

## Структура фронтенда

```text
src/
  assets/brand/       Логотип сервиса
  assets/fonts/       Manrope и лицензия
  assets/icons/
    actions/         Действия: поиск, добавление, удаление
    navigation/      Стрелки, меню, переходы
    decorative/      Разделители и декоративные элементы
    weather/         Солнце, облака, ветер, осадки
    fishing/         Рыба, снасти, способы ловли
    map/             Метки, слои, глубины
    social/          Реакции, комментарии, соцсети
  assets/images/     Иллюстративные фотографии для моков
  components/layout/header/ Хедер
  components/layout/sidebar/ Погода и боковая навигация
  features/weather/  Карточка погоды, типы и изображения состояний
  components/ui/     Кнопки, поля, аватары, метки, выбор и переключатель
  features/feed/     Лента, фильтры, карточка поста и типы
  features/map/      Компоненты и логика карты
  features/fish/     Компоненты и логика справочника
  mocks/
    profile/         Демонстрационный профиль и его публикации
    feed/            Демонстрационные публикации
    weather/         Демонстрационный прогноз
    header/          Демонстрационные данные хедера
    fish/            Рыбы, описания и периоды ловли из макета
  pages/home/        Главная страница
  pages/profile/     Страница профиля
  styles/
    globals.css      Подключение Tailwind и базовые стили
    tokens.css       Переменные темы
    fonts.css        Подключение шрифтов
```

Импорты из `src` используют алиас `@/`, например `@/components/ui/button/Button`. Внутренние модули добавляются по мере разработки.

Иллюстративное фото улова взято с [Unsplash](https://images.unsplash.com/photo-1506873589908-63bc22175dd7). Оно хранится локально и используется только в демонстрационных записях.

## Документация

Раздел «Справочник рыб» открывается из бокового меню. Поиск по названию и фильтр сезона работают вместе на шести моках. Фотографии иллюстративные, описания и периоды взяты из макета и требуют проверки перед использованием как справочных сведений. Источники фотографий перечислены в [src/assets/images/fish/SOURCES.md](src/assets/images/fish/SOURCES.md).

- [Концепция](docs/CONCEPT.md): что делаем, пользовательские сценарии, предлагаемая первая версия, связи данных и открытые решения.
- [Правила для агента](AGENTS.md): обязательные навыки, подход к коду, дизайну, текстам и проверкам. Читать в начале каждой сессии.

## Запуск

Нужны Node.js и npm, совместимые с установленной версией Vite. Зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

## Яндекс Карты

Раздел «Карта мест» открывается из бокового меню. Карта использует JavaScript API v3, начальный центр — Владивосток. Кнопки меняют масштаб и перемещают карту к геопозиции после разрешения браузера. Фильтр и слой глубин пока представлены вёрсткой. Метки и карточка места будут добавлены позже.

Создайте `.env.local` в корне проекта по образцу [.env.example](.env.example) и вставьте браузерный ключ.

```dotenv
VITE_YANDEX_MAPS_API_KEY=ваш_ключ
```

После изменения ключа перезапустите `npm run dev`. В PowerShell с запретом запуска `.ps1` используйте `npm.cmd run dev`.

В кабинете Яндекса заполните ограничение по HTTP Referer для локального адреса разработки и домена сайта. Ключ `VITE_*` доступен в браузере. `.env.local` исключён из Git. Требования к ключу описаны в [документации Яндекса](https://yandex.ru/maps-api/docs/js-api/common/quickstart.html).

Без ключа показывается пустое поле с подсказкой. При ошибке загрузки доступна повторная попытка.

`preview` позволяет посмотреть собранное приложение локально после `build`.
