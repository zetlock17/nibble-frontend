# Иллюстрации полезных материалов

Созданы через imagegen 14 ноября 2026 года для карточек главной страницы «Клёва».

- `fish-identification.png`: декоративные изображения рыб. Не служат определителем видов.

Стиль: мягкие объёмные формы, синие оттенки в палитре рыбака из раздела карты.
